# Retro visual theme

- Palette: neon on dark - background #0a0a1a, accents #ff2079 (pink), #00f0ff (cyan), #f5f543 (yellow)
- All text uses a monospace font and UPPERCASE for headings/HUD labels
- UI elements get a subtle glow (canvas shadowBlur or CSS text-shadow)
- Visual language is 1980s arcade: scanline effects and pixel-styled shapes are welcome
